# 🚀 FastAPI Project - Data Seeding & Fixtures Blueprint

Este documento describe la estructura, el funcionamiento y la guía de uso del sistema de carga de datos de ejemplo para este proyecto de FastAPI.

---

## 📁 1. Estructura del Directorio de Datos

Los datos de ejemplo se encuentran alojados en la carpeta `/data/` ubicada en la raíz del proyecto. Cada archivo corresponde a un parámetro distinto y utiliza la extensión `.json.example` para indicar visualmente que son plantillas de prueba.

```text
 mi_proyecto/
 |
 ├── data/                      <-- Carpeta de datos de ejemplo
 │   ├── parametro1.json.example
 │   ├── parametro2.json.example
 │   ├── parametro3.json.example
 │   └── parametro4.json.example
